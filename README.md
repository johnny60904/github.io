# LanDX Official Professional Web Portfolio

The underlying source module and production deployment repository for the official responsive web portfolio of LanDX (Zi-Cheng Huang). Built in pure, frameworkless **HTML5** and **Modern CSS3**, this system serves as the primary gateway for career profile deployment, architectural project showcase, and professional credential management.

---

## 🌟 Core Architectural Design & Aesthetics
Operating under strict zero-dependency and zero-bloat principles, this personal platform bypasses heavy runtime UI frameworks (e.g., Bootstrap, Tailwind) and reflection-heavy animation libraries. Instead, it leverages:
*   **Native CSS Grid & Flexbox Topography:** Orchestrating an absolute fluid, responsive (RWD) fluid layout grid that dynamically auto-fits device boundaries via native token definitions (`minmax()`).
*   **System-Bound Dark Mode Telemetry:** Implements a hardware-aligned, system-level dark mode environment using native `@media (prefers-color-scheme: dark)` CSS variables, ensuring high-fidelity visual readability and zero-blocking script processing.
*   **Aesthetic Alignment:** The overall color taxonomy (Obsidian Deep Black `#0D1117` fuzed with Microsoft Azure Blue `#00A3EE` and Open-Source Pass Green `#2EA44F`) is completely synchronized with corporate enterprise brand standards.

## 🛡️ Operational Defensive Compliance
*   **Zero Broken Links:** All routing anchors, relative file bridges, and document assets are rigidly hardmarked using strict path boundaries to prevent runtime 404 leakage.
*   **Sanitized Telemetry:** Outside of core open-source projects (`legacy-platform-acl` and `get-files`), proprietary automation scripts are securely managed as closed-source text entities to protect proprietary algorithmic mechanics.
*   **MIT License Adherence:** The structural layout, clean layouts, and CSS token configurations are fully available under the open-source MIT License guidelines.
