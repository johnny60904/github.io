# LanDX Professional Portfolio

The source repository for the official portfolio website of **LanDX (Zi-Cheng Huang)**.

This project is a lightweight, framework-free static website built with native HTML5 and modern CSS3. It serves as the central hub for my professional profile, selected software engineering projects, technical research, and downloadable resumes.

The website focuses on clarity, accessibility, and maintainability rather than framework complexity, demonstrating that a clean architecture can also exist at the frontend presentation layer.
